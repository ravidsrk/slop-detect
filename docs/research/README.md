# Research notes (snapshots)

These folders hold the research and code-status notes written in October 2026 for
roadmap v4. They are dated snapshots, not maintained documentation: pattern counts,
test counts, file paths, line numbers and "shipped / missing" status describe the
code at the commit each note names.

For the current state, read the code, [`ROADMAP.md`](../../ROADMAP.md),
[`AGENTS.md`](../../AGENTS.md) and the open issues. Cite a research note only for
the external sources it quotes, and only after opening the source yourself.
