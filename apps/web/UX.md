# slop-detect.com — UX & User Flows (Phase 1)

Phase 1 turns slop-detect from a one-off scanner into a **viral, shareable
measurement standard**. Every scan now produces a permalink, a shareable card,
a letter grade, and an embeddable badge. This doc is the source of truth for the
flows we build.

## Personas

- **The Scanner** — pastes a URL to see how AI-generated their (or a competitor's)
  page looks. Wants a fast, memorable verdict.
- **The Sharer** — got a spicy result, wants to post it ("my site is an A, yours
  is an F"). Needs a screenshot-friendly card + one-click share.
- **The Embedder** — proud of a Clean grade, wants a live badge in their README /
  site footer. Needs copy-paste snippets.
- **The Crawler** — Twitter/LinkedIn/Slack unfurling a shared permalink. Needs
  server-rendered OG meta + a PNG card.

## Core loop (the growth engine)

```
        ┌────────────────────────────────────────────────────┐
        │                                                     │
        ▼                                                     │
  [1] Land on home  ──►  [2] Paste URL  ──►  [3] Scan result  │
        ▲                                         │           │
        │                                         ▼           │
        │                              [4] Grade + verdict    │
        │                                  + share panel      │
        │                                         │           │
        │            ┌────────────────────────────┼─────────┐ │
        │            ▼                ▼            ▼         │ │
        │      [5a] Share link  [5b] Embed    [5c] Fix      │ │
        │      (X/LinkedIn/    badge in       prompt        │ │
        │       copy → /r/:id)  README/site                 │ │
        │            │                │                     │ │
        │            ▼                ▼                     │ │
        │   [6] Someone opens   [7] Badge renders           │ │
        │       /r/:id permalink    live on their repo      │ │
        │       (OG card unfurls)   (backlink + click)      │ │
        │            │                │                     │ │
        └────────────┴────────────────┴─────────────────────┘ │
                     "Scan your own site" CTA ──────────────────┘
```

Each shared card and embedded badge recruits the next Scanner. That's the loop.

## Flow A — Scan (enhanced)

1. Home (`/`): headline, URL input, example chips.
2. Submit → `POST /api/scan` (Turnstile + rate-limited as today).
3. Result renders inline with **new elements**:
   - Big **letter grade** (A+…F) next to the 0–100 score.
   - **Verdict one-liner** (deterministic, punchy, never insulting a person).
   - Triggered / clean pattern lists (as today, collapsible evidence).
   - **Share panel** (Flow B) + **Embed panel** (Flow C) + Fix-prompt CTA.
4. The scan is **persisted** to KV; the response includes `id` + `resultUrl`
   (`/r/<id>`). The URL bar updates to the permalink (history.replaceState).

## Flow B — Share

- Share panel shows the permalink + three actions:
  - **Copy link** → `slop-detect.com/r/<id>`
  - **Share on X** → prefilled intent with verdict + link
  - **Share on LinkedIn** → share URL
- Opening `/r/<id>` (Flow D) gives crawlers an OG card so the link unfurls with
  a big grade image.

## Flow C — Embed badge

- Embed panel shows a **live preview** of the badge + copy-paste snippets:
  - Markdown: `[![slop](https://slop-detect.com/badge/<domain>.svg)](https://slop-detect.com/r/<id>)`
  - HTML `<img>` one-liner
  - Plain badge URL
- Badge endpoint `GET /badge/<domain>.svg` returns a live, tier-colored SVG
  ("slop · A · 6"). Cached; re-scans at most every few hours per domain.

## Flow D — Permalink (`/r/:id`)

- **Server-rendered** HTML (works without JS, crawler-friendly).
- OG/Twitter meta point at `GET /og/<id>.png` (the share card).
- Shows the full result: grade, score, tier, verdict, triggered patterns,
  scanned URL + timestamp + definitions version.
- Primary CTA: **"Scan your own site →"** (loops back to home) — the viral return.
- Secondary: copy badge snippet, view fix prompt.

## Flow E — OG card (`/og/:id.png`)

- 1200×630 PNG generated by rendering a card layout and screenshotting it via
  Cloudflare Browser Rendering (`page.setContent` + screenshot), cached in KV.
- Layout: wordmark · huge grade letter · score/100 · tier pill · scanned domain
  · verdict · `slop-detect.com` footer.

## Data model (KV: `RESULTS`)

| Key | Value | TTL |
|---|---|---|
| `r:<id>` | full scan result JSON (+ grade, verdict, createdAt) | 90d |
| `d:<domain>` | latest `<id>` for that domain | 90d |
| `og:<id>` | base64 PNG of the share card (cache) | 30d |
| `badge:<domain>` | cached SVG (short cache) | ~3h |

## Non-goals (Phase 1)

- No accounts, no auth, no historical tracking (that's Phase 4 Pro).
- No DB — KV is enough for immutable result snapshots.
- Badge does not guarantee real-time freshness; it reflects the last scan.
